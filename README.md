# Solução Analítica Interativa para Monitoramento de Sinistros Rodoviários em Goiás

### Sinistros em Rodovias Federais (BR-GO) • 2024–2025
*Uma abordagem de Business Intelligence e Data Storytelling para apoio à decisão.*

---

## 📌 Sobre o Projeto
Este projeto integrador de caráter extensionista, desenvolvido para o curso de Big Data e Inteligência Artificial da PUC-GO, propõe uma solução analítica interativa para explorar a base de dados públicos de sinistros da Polícia Rodoviária Federal (PRF). O objetivo central é converter registros estatísticos dispersos em uma narrativa visual contínua, servindo como uma ferramenta de suporte opcional para consulta analítica voltada à segurança viária em todo o território goiano.

---

## 🎯 Diferenciais do Dashboard
O painel foi arquitetado sob o conceito de Data Storytelling investigativo, dividindo a experiência do usuário de forma sequencial e fluida para entregar valor passo a passo:
* **Abordagem Pedagógica:** A navegação orienta o leitor de forma amigável, partindo de um panorama macro para uma investigação focada em regularidades temporais, culminando na validação empírica das hipóteses estudadas.
* **Quebra de Vieses Estatísticos:** O design prioriza o contraste imediato de métricas essenciais, auxiliando o tomador de decisão a confrontar o senso comum sobre fatores ambientais e comportamentais na sinistralidade.
* **Foco na Relação Causa-Efeito:** Diferentes dimensões de dados (temporais, espaciais e humanas) foram correlacionadas de maneira complementar para evidenciar padrões consistentes e recorrentes ao longo do biênio.
* **Mapeamento de Criticidade:** Consolida o cruzamento multifatorial de coordenadas geográficas no período de maior adensamento de tráfego, oferecendo um mecanismo simplificado de localização de pontos de maior vulnerabilidade.
* **Performance Otimizada:** Desenvolvido com técnicas de engenharia de software para garantir consultas rápidas, renderização responsiva e uma interface web leve diretamente via navegador de internet.

## 🛠️ Tecnologias Utilizadas
* **Python:** Linguagem base para processamento de dados e lógica da aplicação.
* **Streamlit:** Framework para construção da interface web interativa.
* **Plotly:** Biblioteca para renderização de gráficos e mapas dinâmicos.
* **Pandas:** Manipulação, limpeza e agregação de dados.

## 👤 Engenharia do Projeto e Papel do Idealizador
Este projeto foi concebido e estruturado com base no conceito de **Desenvolvimento Aumentado por Inteligência Artificial (AI-Augmented Development)**. Todo o ciclo de vida da solução foi liderado de forma estratégica pelo desenvolvedor, que atuou como o arquiteto analítico do sistema, utilizando ferramentas de IA generativa como copilotos para potencializar a produtividade técnica, otimizar o fluxo de engenharia e garantir a entrega de um código fonte limpo e eficiente.

### Responsabilidades e Liderança Técnica:
* **Idealização e Tese de Negócio:** Formulação das hipóteses analíticas, definição das perguntas de negócio e proposição da solução final.
* **Arquitetura de Inteligência Artificial:** Estruturação dos prompts, refinamento lógico, governança das diretrizes do sistema e condução da IA para geração de soluções de código limpo.
* **ETL e Engenharia de Dados:** Planejamento do fluxo de extração, tratamento, limpeza e transformação da base de dados original.
* **Cruzamento de Dados e Modelagem:** Definição das relações entre variáveis temporais, espaciais, climáticas e estruturais da via.
* **Design de UX/UI e Storytelling Visual:** Concepção da identidade visual, organização do grid em colunas, definição de cards informativos e sequenciamento narrativo do dashboard.
